# หม้อเดียว — ครัวญี่ปุ่นฉบับง่าย

เว็บแอปสูตรอาหารภาษาไทยสำหรับทำเมนูญี่ปุ่นด้วยหม้อไฟฟ้าธรรมดา มี 10 เมนู รูปอาหารจริงที่เก็บไว้ในเครื่อง พร้อมภาพ SVG สำรอง รายการวัตถุดิบ วิธีทำทีละขั้น และเมนูโปรดที่บันทึกไว้ในเบราว์เซอร์

## เปิดใช้งานบน Windows

ดับเบิลคลิก `start-app.cmd` เพื่อเปิดเว็บแอปและเริ่ม local server ในหน้าต่างที่ย่อไว้ ปิดหน้าต่าง server เมื่อเลิกใช้ หากไม่ต้องการใช้ server สามารถเปิด `index.html` ในเบราว์เซอร์ได้โดยตรง

แอปไม่มี dependency และไม่มีการเรียกไฟล์หรือบริการจากอินเทอร์เน็ต รูปอาหารและสูตรอยู่ในโปรเจกต์ ใช้งานได้โดยไม่ต่ออินเทอร์เน็ต เครดิตและสัญญาอนุญาตรูปอยู่ใน `assets/recipes/credits.html`

## เมนูเริ่มต้น

ข้าวหน้าไก่ไข่, ข้าวหน้าเนื้อ, ข้าวแกงกะหรี่ญี่ปุ่น, ข้าวต้มญี่ปุ่น, คิทสึเนะอุด้ง, ซุปมิโสะเต้าหู้, หม้อไฟหมูผัก, มันฝรั่งตุ๋นเนื้อ, ราเมงมิโสะข้าวโพด และสลัดมันฝรั่งญี่ปุ่น

> ใช้หม้อไฟฟ้าตามคู่มือของรุ่นที่มี ระวังไอน้ำและอาหารร้อน ปรุงเนื้อสัตว์ให้สุกทั่ว และถอดปลั๊กก่อนล้างหม้อ

## ฟีเจอร์

- 15 สูตร (มีเมนูไม่ใส่เนื้อสัตว์และของหวาน) ภาษาไทยและภาษาอังกฤษ (ปุ่ม EN ด้านบน)
- โหมดทำอาหารทีละขั้น: จับเวลาจากเวลาในสูตร (+1/+3 นาที เตือนก่อนหมด 1 นาที), เปิดจอค้าง, อ่านออกเสียง, ปรับขนาดตัวอักษร, ทำต่อจากที่ค้างได้
- ปรับปริมาณ ½×–3×, คำนวณเวลาเริ่มทำจากเวลาที่อยากกิน, ของทดแทน, คำอธิบายศัพท์, โน้ต, พิมพ์สูตร, แชร์ลิงก์ `#recipe=<id>`
- รายการซื้อของ (รวมของซ้ำได้), แผนเมนูประจำสัปดาห์, ค้นจากของในตู้เย็น, ตัวกรองสิ่งที่ไม่กิน
- เพิ่มสูตรเองพร้อมรูป หรือวางสูตรเป็นข้อความแล้วให้แยกใส่ฟอร์มให้, ประวัติการทำและให้ดาว, โหมดมืด
- รองรับจอ 320px ถึง 2560px: มือถือและแท็บเล็ตมีแถบเมนูด้านล่าง ปุ่มกดได้ขนาดอย่างน้อย 44px
- ติดตั้งเป็นแอป (PWA) ใช้งานออฟไลน์ได้ ข้อมูลเก็บในเบราว์เซอร์ สำรอง/นำเข้าเป็นไฟล์ JSON ได้ที่ท้ายหน้า

## สำหรับนักพัฒนา

| ไฟล์ | หน้าที่ |
|---|---|
| `recipes.js` | ข้อมูลสูตร (ภาษาไทย) |
| `i18n.js` | โหมดภาษาอังกฤษ: สูตรภาษาอังกฤษ + คำแปลหน้าจอ |
| `core.js` | ฟังก์ชันคำนวณล้วน (ปรับปริมาณ แยกวัตถุดิบ รวมรายการ จับเวลา) ใช้ได้ทั้งเบราว์เซอร์และ Node |
| `app.js` | หน้าจอหลัก รายละเอียดสูตร โหมดทำอาหาร รายการซื้อของ แผน |
| `features.js` | สูตรของฉัน ตู้เย็น ตัวกรอง คำศัพท์ ลิงก์ แถบเมนูมือถือ |
| `sw.js` | แคชออฟไลน์ — **เปลี่ยน `VERSION` ทุกครั้งที่แก้ไฟล์** |

```bash
npm install          # ครั้งแรก (Prettier + Playwright)
npm start            # เปิดที่ http://127.0.0.1:8000
npm test             # unit test ของ core.js และข้อมูลสูตร
npm run test:e2e     # ทดสอบในเบราว์เซอร์ (ใช้ Google Chrome ในเครื่อง) รวม 8 ขนาดหน้าจอ
npm run format       # จัดรูปแบบโค้ด
```

โค้ดใช้สัญญาอนุญาต MIT (ดู `LICENSE`) ส่วนรูปอาหารใช้สัญญาอนุญาตของแต่ละภาพ ดู `assets/recipes/credits.html`
